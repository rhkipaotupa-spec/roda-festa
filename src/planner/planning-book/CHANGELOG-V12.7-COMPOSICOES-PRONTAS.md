# V12.7 - Composicoes prontas da Cena Viva

- A Cena Viva passa a usar imagens completas de carrinhos e mesas.
- Removido o posicionamento de alimentos sobre carrinhos por CSS.
- Seletor automatico:
  - car-frituras.png para frituras;
  - car-burger.png para apenas burger;
  - car-hot-dog.png para apenas hot dog;
  - car-burger-hot-dog.png para burger + hot dog;
  - car-drinks.png para bebidas;
  - table-bolo.png para apenas bolo;
  - table-doces.png para apenas doces;
  - table-bolo-doces.png para bolo + doces.
- Doces e bolo permanecem separados da contagem de carrinhos.
- Cena responsiva no desktop e com rolagem horizontal dos objetos no celular.

IMPORTANTE: manter os oito PNGs dentro de `planning-book/assets/`.
