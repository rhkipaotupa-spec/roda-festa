# V10.2 - Hierarquia e consistencia visual

- A acao "Conhecer recomendacao" foi movida para o topo do resumo, ao lado do tipo de evento.
- A tela de resumo fechado foi compactada para caber sem rolagem vertical.
- O espaco vazio entre o resumo salvo e a navegacao foi eliminado.
- A etapa Recomendacao continua inativa ate o cliente abrir o conteudo.
- A distribuicao dos carrinhos passou a usar a mesma linguagem visual dos cards de estacoes.
- A pagina de personalizacao agora reutiliza o layout aprovado de detalhes da estacao.
- Motor operacional, quantidades, investimento e cena foram preservados.
