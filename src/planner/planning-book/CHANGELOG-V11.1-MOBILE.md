# V11.1 — Mobile First

- O desktop continua em três colunas: página 1, página 2 e visualização.
- No celular, as três áreas são empilhadas verticalmente.
- Ordem mobile: página 1 → página 2 → visualização.
- Ao gerar a recomendação, a página rola suavemente para a análise.
- Ao abrir a recomendação, a página rola suavemente para a página 2.
- Formulários, cards e botões ocupam a largura disponível.
- A barra de progresso permanece navegável horizontalmente sem quebrar o layout.
- A área de geração fica acessível no rodapé da primeira página.
- Safe area de celulares foi considerada no botão inferior.
- A visualização mantém altura suficiente para funcionar como terceiro capítulo.
- Nenhuma regra do motor foi alterada.
