# SITE RODA-FESTA — Design System

## Direção visual

- premium;
- cinematográfica;
- elegante;
- escura;
- quente;
- dourada;
- com iluminação controlada.

## Cores conceituais

- preto/marrom quase preto para fundo;
- dourado quente para destaques;
- creme para áreas claras e CTA;
- marrom escuro para texto dentro do botão claro;
- branco quente para títulos principais.

## Tipografia

- títulos emocionais: serifada, elegante;
- textos funcionais e CTA: sans-serif forte, caixa alta e espaçamento controlado;
- evitar aparência genérica de formulário.

## Movimento

- entrada por fade e reveal;
- brilho respirando lentamente;
- aro com reflexos circulando;
- microinterações discretas;
- evitar animações chamativas ou artificiais;
- respeitar `prefers-reduced-motion`.

## Componentes

### Botão principal

- usa a cápsula clara presente na composição;
- texto centralizado;
- sem seta;
- hover discreto, sem salto vertical exagerado;
- alta legibilidade.

### Roda

- elemento de assinatura;
- pode girar lentamente;
- marrom escuro quando sobre fundo claro;
- dourada quando sobre fundo escuro;
- nunca deve competir com o título.

### Recomendações

- verde: excelente;
- amarelo: atenção/recomendação;
- vermelho: risco;
- sempre acompanhadas de texto explicativo e ação sugerida.
